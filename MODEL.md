# Limits Before Scale Model

The core idea:

Scale amplifies the structure of a system.

If limits grow proportionally with scale, the system remains stable.

If scale grows faster than limits, instability emerges.

## Basic Model

System = Structure + Limits

Scale increases complexity.

Limits increase control.

Stability depends on the balance between complexity and control.
